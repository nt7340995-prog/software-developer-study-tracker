# Software Developer Study Tracker

A web-based study tracking application designed to help learners organize their technical learning journey, maintain consistent study habits, and monitor progress through a structured 40-day learning challenge.

## Overview

The Software Developer Study Tracker allows users to track their progress across 16 technical topics, mark daily learning goals as completed, calculate completion scores, and maintain individual study notes for each topic and day.

The application provides a centralized dashboard for managing learning activities and visualizing progress toward software development goals.

## Key Features

* **Topic-Based Learning:** Organize learning across 16 software development and AI-related topics.
* **40-Day Learning Challenge:** Track daily progress independently for each topic.
* **Progress Monitoring:** View completed days, remaining days, topic completion percentages, and overall progress.
* **Interactive Dashboard:** Navigate between topics and track learning activities through an interactive interface.
* **Daily Study Notes:** Write and save notes separately for each topic and day.
* **Progress Persistence:** Store progress and notes using browser Local Storage.
* **Responsive Interface:** Access the application on different screen sizes, including desktop and mobile browsers.

## Getting Started

### Prerequisites

* A modern web browser
* Git (optional, for cloning the repository)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/nt7340995-prog/software-developer-study-tracker.git
```

**2. Navigate to the project directory**

```bash
cd software-developer-study-tracker
```

**3. Run the application**

Open `index.html` in your web browser.

No additional packages or dependencies are required for the basic frontend application.

## How to Use

1. Open the application in your browser.
2. Select a topic from the topic list.
3. Choose a day from the 40-day challenge.
4. Mark the day as completed when you finish your study session.
5. Record concepts learned, code examples, and questions in the daily notes section.
6. Monitor topic-wise and overall progress through the dashboard.
7. Revisit previous notes to revise important concepts.

## Data Storage

The application uses browser Local Storage to retain study progress and daily notes.

**Note:** Stored data is browser-specific. Progress saved on one device or browser does not automatically synchronize with another device.
